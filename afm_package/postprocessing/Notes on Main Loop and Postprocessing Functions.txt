How plot_npy.py works:

When called the run_all.py file asks for a specific path to the .npy file one wishes to analyze. Then one is asked to specify which axis to slice.

a postprocessing function loads the data to be plotted from "phi" which itself is phi = np.load(phi_file) where phi_file is just the .npy file that was generated

Loads the .npy file, saving a matrix of the potentials of the box as "phi" and the size of each axis as nx, ny, nz.

For the purpose of generating the Electric field it defines infinitesimals with which to calculate the gradient of the potential (unsure if this is arbitrary or must = box size)

Defines the arrays x, y, and z, where the former 2 are defined from -0.5 to 0.5, the latter from 0 to 1, each in steps of nx, ny, nz, respectively. These are used as the x-axis for the plots

Defines infinitesimals ix, iy, iz, to find the exact midpoints of the phi matrix, these are hardcoded to multiply eg. 0.5*(nx-1)
